## Kimi Balance 1.3

Kimi Balance 1.3 重新设计了设置页面，并将状态栏展示内容升级为可自由组合的多选配置，新增双圆形用量进度条。

### 更新内容

- 设置页面改为顶部标签页布局，将“Menu Bar”“How to Use”“About”拆分为三个独立页面，不再纵向排列所有内容。
- “Menu Bar”页面提供头像、文字和圆形进度条三个独立选项，支持多选和自由组合，切换后立即生效并自动保存。
- 新增双圆形进度条，分别展示总使用量和 5 小时用量；支持单独显示，也支持与头像、文字同时显示。
- 圆形进度条采用加宽线条和系统模板颜色，可跟随菜单栏背景及深色、浅色外观自动调整显示颜色。
- 头像与圆形进度条同时启用时，两项内容会并排显示；文字可根据选择独立显示或隐藏。
- 至少保留一个状态栏展示选项，避免全部关闭后无法找到应用入口。
- 自动迁移旧版本的头像与文字、仅头像、仅文字和圆形进度条展示模式，升级后保留原有显示偏好。
- 更新 README 功能及设置说明，补充多选组合和双圆形进度条的使用方式。

### 版本信息

- 应用版本：1.3
- 编译版本：4
- 系统要求：macOS 26.6.2 或更高版本

### 安装与升级

- 全新安装：下载并打开 `Kimi-Balance.dmg`，将 Kimi Balance 拖入“应用程序”文件夹。
- 自动更新：在已有版本的菜单栏中选择“检查更新…”。
- 安装包经过 Developer ID 签名和 Apple 公证。
