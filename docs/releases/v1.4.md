## Kimi Balance 1.4

Kimi Balance 1.4 增强了菜单栏内容自定义、后台刷新设置和窗口管理，并完善了开机自动启动与 Sparkle 更新提醒。

### 更新内容

- 新增开机自动启动功能，默认开启；可在设置的“General”页面关闭，应用会保存用户选择。
- “Menu Bar”页面支持通过拖动调整头像、文字和圆形进度条的排列顺序，菜单栏立即按照新顺序显示，重启后保留设置。
- “General”页面新增使用量刷新频率滑块，默认每 60 秒刷新，可在 30 秒至 30 分钟之间调整，步长为 30 秒。
- 刷新频率调整后立即应用到后台定时器，无需重启应用；关闭主窗口后仍会按照所选频率刷新用量。
- 主窗口或设置页面已经打开时，再次选择菜单栏中的对应命令会复用已有窗口并将其置前；最小化的窗口会自动恢复。
- 完善窗口关闭后的 Dock 图标管理，主窗口或设置窗口仍打开时继续显示 Dock 图标，全部关闭后恢复为仅菜单栏模式。
- 接入 Sparkle 温和更新提醒，自动检查发现新版本时将菜单项标记为“有可用更新…”，点击后继续使用 Sparkle 标准更新界面。
- 更新会话结束后自动恢复“检查更新…”菜单标题，避免更新提示残留。
- 修正刷新频率滑块的横向布局，使轨道铺满标签之间的可用空间，并保持两端间距一致。
- 更新 README 功能与使用说明，补充开机启动、拖动排序、窗口管理、更新提醒和刷新频率配置。

### 版本信息

- 应用版本：1.4
- 编译版本：5
- 系统要求：macOS 26.6.2 或更高版本

### 安装与升级

- 全新安装：下载并打开 `Kimi-Balance.dmg`，将 Kimi Balance 拖入“应用程序”文件夹。
- 自动更新：在已有版本的菜单栏中选择“检查更新…”。
- 安装包经过 Developer ID 签名和 Apple 公证。
