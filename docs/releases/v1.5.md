## Kimi Balance 1.5

Kimi Balance 1.5 新增完整的中英文界面支持，可根据系统语言自动选择，也可在设置中即时切换；同时补全了英文模式下重置时间的本地化显示。

### 更新内容

- 在“通用 / General”设置页新增“语言 / Language”选项，支持简体中文和英文。
- 首次启动时自动跟随 macOS 首选语言，用户选择会保存在应用偏好设置中。
- 语言切换后立即应用到主窗口、设置页、菜单栏用量详情和操作菜单，无需重启应用。
- 完成登录提示、用量展示、刷新操作、使用指南、关于信息、检查更新、退出及无障碍说明等应用自有文案的中英文本地化。
- 使用 macOS 原生 String Catalog 管理中英文资源，并在项目配置中声明英文和简体中文支持。
- 用量数据提取兼容 Kimi 订阅页面的中英文“总使用量”和“5 小时用量”标题。
- 修复英文模式下重置时间仍显示中文“后重置”的问题；例如 `2026-12-11 10:07 后重置` 现在显示为 `Reset after 2026-12-11 10:07`。
- 重置时间转换同时应用于主窗口和菜单栏，切换语言后立即更新，无需等待下一次后台刷新。
- 更新 README，补充多语言功能、语言切换路径、偏好保存和即时生效说明。

### 版本信息

- 应用版本：1.5
- 编译版本：6
- 系统要求：macOS 26.6.2 或更高版本

### 安装与升级

- 全新安装：下载并打开 `Kimi-Balance.dmg`，将 Kimi Balance 拖入“应用程序”文件夹。
- 自动更新：在已有版本的菜单栏中选择“检查更新…”。
- 安装包经过 Developer ID 签名和 Apple 公证。
