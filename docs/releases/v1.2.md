## Kimi Balance 1.2

Kimi Balance 1.2 新增设置页面和英文操作指南，并完善了项目使用文档。

### 更新内容

- 新增设置页面，提供从启动、登录到查看和刷新用量的完整英文操作流程。
- 菜单栏新增“设置…”入口，支持 `Command + ,` 快捷键，并可复用、缩放和最小化设置窗口。
- 设置页面展示应用版本号、编译版本号、GitHub 仓库和 Kimi 订阅数据来源链接。
- 增加登录 Cookie 本地存储及用量数据来源说明。
- 更新 README 菜单栏截图，补充启动、登录、刷新、设置、更新、退出和常见问题说明。

### 版本信息

- 应用版本：1.2
- 编译版本：3
- 系统要求：macOS 26.6.2 或更高版本

### 安装与升级

- 全新安装：下载并打开 `Kimi-Balance.dmg`，将 Kimi Balance 拖入“应用程序”文件夹。
- 自动更新：在已有版本的菜单栏中选择“检查更新…”。
- 安装包经过 Developer ID 签名和 Apple 公证。
