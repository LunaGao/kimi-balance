## Kimi Balance 1.6

Kimi Balance 1.6 为菜单栏圆形进度增加内部到期圆环，可在查看总使用量和 5 小时用量的同时，直观了解各自距离下次重置的时间进度；同时新增独立显示开关，并完善不同重置时间格式的兼容性。

### 更新内容

- 菜单栏总用量和 5 小时用量圆环内部新增小圆环，分别展示距离下次重置的已流逝时间比例。
- 总用量内圈按一个月周期计算，5 小时用量内圈按五小时周期计算。
- 内圈每分钟自动更新，即使用户调长用量数据刷新间隔，时间进度也会持续推进。
- 调整圆环视觉比例：缩小外圈线宽，加粗并适当放大内圈，提升两个小圆环的辨识度。
- 在“设置 → Menu Bar”新增“显示内部到期圆环 / Show Inner Expiration Rings”开关，可同时显示或隐藏两个内圈，不影响外圈用量展示。
- 内圈开关默认开启，设置会保存在应用偏好设置中并立即生效；未启用“圆形进度”时，该开关自动禁用。
- 新增内圈开关的简体中文和英文文案，并更新 README 功能说明。
- 重置时间解析支持完整日期格式，例如 `2026-12-11 10:07 后重置` 和 `Reset after 2026-12-11 10:07`。
- 修复 5 小时内圈不显示的问题，兼容页面实际使用的无年份格式，例如 `11-26 20:07 后重置`，并正确处理跨年日期。
- 兼容中英文相对倒计时格式，包括天、小时、分钟和秒，例如 `2小时28分后重置`、`2h 28m 后重置` 和 `Reset in 2 hours 28 minutes`。
- 相对倒计时在获取用量数据时转换为固定重置日期，避免每分钟重绘时倒计时原地不变。

### 版本信息

- 应用版本：1.6
- 编译版本：7
- 系统要求：macOS 26.6.2 或更高版本

### 安装与升级

- 全新安装：下载并打开 `Kimi-Balance.dmg`，将 Kimi Balance 拖入“应用程序”文件夹。
- 自动更新：在已有版本的菜单栏中选择“检查更新…”。
- 安装包经过 Developer ID 签名和 Apple 公证。
